Implements the streaming telemetry subsystem for our network operating system, under a Senior Engineers guidance.
Key Responsibilities
Implement telemetry data collectors for protocol state, interface statistics, and system metrics
Implement YANG-Push subscriptions (RFC 8641) and gRPC/gNMI streaming (Subscribe RPC, JSON_IETF/protobuf encoding)
Implement a Prometheus exporter and OpenTelemetry (OTLP) integration for metrics and traces
Write comprehensive unit tests for data collectors, subscriptions, and exporters, and measure collection overhead
Debug the telemetry pipeline end to end - from collectors to exporters - verifying data accuracy and encoding

0-3 years of software development experience (fresh graduates with strong Python/systems monitoring skills welcome)
Strong understanding of systems monitoring and observability concepts
Hands-on experience with Python programming and data collection (coursework or personal projects)
Basic knowledge of networking concepts (interfaces, protocols, network statistics)
Nice to Have
Personal projects involving system monitoring or telemetry collection
Open-source contributions to monitoring tools (Prometheus exporters, Telegraf plugins)
Experience with time-series databases (InfluxDB, Prometheus, Grafana)
Understanding of SNMP protocol and MIB structure
